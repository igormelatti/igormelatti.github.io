Click on the following link to download a file with all logs: TGZ.

File name conventions:

  • networkname.full.log: log for the main execution (read the input network file, write the not-reduced ILP, perform the reductions, write the reduced ILP)
  • networkname.x.lp.log: GLPK log for the NIP instance (networkname, x) without reductions
  • networkname.x.lp.reach_chain_detour.lp.log: GLPK log for the NIP instance (networkname, x) with all reductions
