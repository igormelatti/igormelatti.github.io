The same results in the above files are presented in the following HTML table.

All execution times are in seconds. All memory peaks are in kB.

  • name: Name of the graph as it is in the SNAP
  • notes: Whether computation hit a timeout or not
  • no_red_time, no_red_mem_peak: time to read the input file and create the ILP (state-of-the-art procedure)
  • reach_chain_time_time, reach_chain_time_mem_peak: execution time and memory peak to perform reachability and chain reduction only
  • detour_time_time, detour_time_mem_peak: execution time and memory peak to perform detour reduction only
  • all_time, all_mem_peak: execution time and memory peak to perform all reductions (reachability, chain and detours)
  • all_write_time, all_write_mem_peak: execution time and memory peak to read the input file, perform all reductions and create the ILP (new proposed procedure)
  • no_red_nodes, no_red_edges: number of nodes and edges of the original network
  • reach_chain_nodes, reach_chain_edges: number of nodes and edges of the network after reachability and chain reduction
  • detour_nodes, detour_edges: number of nodes and edges after detour reduction
  • B_i: value for the budget of the i-th NIP instance of the current network
  • Obj_i: value for the GMF (Guaranteed Maximum Flow) for the i-th NIP instance of the current network
  • Obj_approx_i: value for the GMF (Guaranteed Maximum Flow) as computed by the approximated algorithm with ε=0.1 for the i-th NIP instance of the current network
  • time_no_red_i, mem_no_red_i: execution time and memory peak to solve the ILP of the i-th NIP instance of the current network without reductions
  • time_reach_chain_detour_i, mem_reach_chain_detour_i: execution time and memory peak to solve the ILP of the i-th NIP instance of the current network with all reductions (reachability, chain and detour)
  • time_reach_chain_detour_i, mem_reach_chain_detour_i: execution time and memory peak to solve the ILP of the i-th NIP instance of the current network with all reductions (reachability, chain and detour)
  • time_approx_i, mem_approx_i, num_iter_approx_i: execution time, memory peak and number of iterations (shown also for non-completed computations) required by the approximated algorithm with ε=0.1 for the i-th NIP instance of the current network
